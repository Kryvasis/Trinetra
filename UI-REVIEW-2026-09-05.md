- Fixed Results losing loaded evidence on a failed refresh. Existing results now
  remain visible with clear stale-result wording and retry. Switching assessments
  clears old evidence; PDF export captures its session and cancels on selection change.
- Added a workspace render-error boundary so the navigation remains reachable,
  and corrected unknown-route browser titles.
- Fixed notification ID collisions, duplicate notices, excessive stacking and
  timer cleanup in the shared app notification owner.
- Added shared session-name validation to Overview, Devices and Training, with
  focus and accessible errors. Results also exposes invalid field state.
- Added Devices search, clear, ten-row pagination, page clamping, readable
  mobile controls and a keyboard-accessible horizontal table region.
- Fixed device Cancel/Escape focus restoration and a focus fallback after removal.
  Reused robust numeric aggregation. Missing OS metadata is explicitly unknown;
  device pass rates no longer claim overall compliance or color uncertainty as failure.
- Fixed Training claiming lines were already trained on initial load and showing
  the original count when zero remained. Counts now describe local review progress.
  Associated form labels and validation messages, focused the first invalid field,
  disabled pending fields and wrapped the summary on narrow screens.

## Limits

This improves the inspected workflows; it is not a claim of full production
readiness or an exhaustive accessibility/device audit. Backend deployment,
authentication, evidence privacy and broader rule accuracy retain their previously
documented limitations. Native select popup appearance remains platform-owned.
Device search and pagination operate on the API's loaded inventory; server paging
would be needed for very large deployments. No real network scans or user-data
removal were needed for verification. No packages were added.
