# Trinetra Skills Map

## Core engineering skills required
- Java CLI application design.
- Bash shell orchestration.
- JSON schema design and file persistence.
- API integration with curl/jq.
- Prompt engineering for bounded summarization and recommendation.
- Pentest workflow design and vulnerability taxonomy handling.

## Security skills embodied by the framework
- Recon and OSINT analysis.
- Web and API vulnerability testing.
- AuthN/AuthZ validation.
- Infrastructure and crypto misconfiguration analysis.
- Session and state handling for repeatable audits.

## AI workflow skills
- Incremental memory patching.
- Markdown compression and regeneration.
- Structured suggestion generation.
- Session-aware question answering.
- Cross-session activity summarization.

## Future expansion skills
- Additional cert/reporting frameworks.
- More V-code coverage.
- Richer IDE automation.
- Automated revalidation workflows.
- Broader provider abstraction for LLM backends.
