# Cortex

Cortex is an SIH cybersecurity configuration-assurance project for collecting network evidence, evaluating mapped checks, reviewing findings, and exporting assessment reports. It includes tamper-evident research primitives—a hash chain, Merkle commitment and local Ed25519 signature—but does not claim blockchain anchoring. It runs as a local React/Vite application backed by existing Python and Java services. Production deployment and multi-user authentication are not established.

The primary users are operators and assessors working with authorized configurations and network targets. They need honest evidence, explicit collection consent, readable results, and clear recovery from missing or failed assessments. A pass rate is not a compliance certification. Website observations are separate from configuration checks.

The approved opening animation remains untouched. Open workspace leads to an overview, followed by separate Upload & collect, Results, Devices, Training, Assurance, and System pages. Assurance publishes implementation coverage and verifies locally signed evidence receipts without claiming external blockchain anchoring. The user requested a direct implementation of their supplied near-black NEXORA dashboard reference: graphite rounded panels, white active navigation, compact typography, and restrained functional animation. No fake alerts, histories, people, telemetry, decorative neon, or purple gradients.

Keep the current technology stack and all existing workflows. Optimize for desktop assessment work with usable narrow-screen layouts, keyboard focus, and reduced motion. No deployment, package upgrade, or external scanning is authorized by this redesign.
